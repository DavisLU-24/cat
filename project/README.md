# 旅行小猫 - 上海海事大学版

一款基于 Pygame 的桌面养成游戏，玩家扮演「铲屎官」，喂养小猫、补充能量，派它去上海海事大学校园的 7 个地标旅行，收集明信片、徽章、宝物三类纪念品。

## 技术架构

### 三层分离架构

```
┌─────────────────────────────────────────┐
│  前端 (frontend/)                        │
│  Pygame 窗口、UI 组件、渲染、音效         │
│  只调用 api.xxx()，不写 SQL              │
└──────────────────┬──────────────────────┘
                   │ GameAPI
┌──────────────────▼──────────────────────┐
│  后端 (backend/)                         │
│  游戏逻辑：猫、能量、旅行、背包、存档      │
│  只调 Repository 或 data 模块             │
└──────────────────┬──────────────────────┘
                   │ GameRepository
┌──────────────────▼──────────────────────┐
│  数据层 (backend/db/ + data/travel_cat.db)│
│  SQLite 表 + 种子数据 + 迁移脚本          │
└─────────────────────────────────────────┘
```

### 技术选型

- **前端**: Pygame (2D 窗体游戏引擎)
- **后端**: Python (游戏逻辑)
- **数据层**: SQLite + JSON 双存储
- **通信方式**: 同进程方法调用（GameAPI）

## 游戏机制

### 能量系统

- 能量范围：0-200
- 初始能量：100
- 喂食：增加能量（上限 200）
- 旅行：消耗能量

### 7 个地标

| 地标          | 最低能量 | 消耗能量 |
|---------------|----------|----------|
| 操场          | 20       | 30       |
| 羽毛球馆      | 20       | 30       |
| 智慧湖        | 25       | 35       |
| 灯塔          | 30       | 40       |
| 大礼堂        | 30       | 40       |
| 中远图书馆    | 35       | 45       |
| 吴淞号船      | 40       | 50       |

每个地标包含：5 张明信片 + 2 个徽章 + 1 个宝物

### 旅行流程

1. 选择地标（或随机旅行）
2. 校验能量 ≥ 最低能量
3. 扣除能量，小猫开始旅行
4. 旅行时间：30 秒 + 最低能量加成 ± 20% 随机
5. 旅行完成，获得奖励

### 奖励规则

- **必得**：1 张明信片
- **徽章**：出发前能量 ≥50，30%-80% 概率获得
- **宝物**：出发前能量 >100，10%-60% 概率获得

### 存档系统

- 10 个存档槽位
- SQLite 主存储 + JSON 备份
- 支持读档恢复：小猫状态、背包、旅行历史、已解锁地标


### 从 SQLite 导出到 JSON

```bash
# 导出所有槽位
python scripts/migrate_data.py db2json

# 导出指定槽位
python scripts/migrate_data.py db2json --slot 1
```

## 开发说明

### 前后端分离原则

1. **前端** 只调用 `api.xxx()` 方法，不直接访问数据库
2. **后端** 只调用 `Repository` 或 `data` 模块，不依赖 Pygame
3. **GameAPI** 返回统一格式：`{"success": bool, "message": str, ...}`

### 添加新地标

1. 在 `backend/data/landmarks.py` 添加地标数据
2. 在 `backend/data/items.py` 添加对应收集品
3. 重新运行游戏，种子数据自动灌入

### 添加新食物

1. 在 `backend/data/foods.py` 添加食物数据
2. 重新运行游戏，种子数据自动灌入

## 数据库表结构

### 静态配置表
- `Foods`: 食物
- `Landmarks`: 地标
- `Items`: 收集品

### 玩家数据表
- `SaveSlots`: 存档槽位
- `CatState`: 小猫状态
- `PlayerInventory`: 背包
- `TravelHistory`: 旅行历史
- `TravelRewards`: 旅行奖励
- `UnlockedLandmarks`: 已解锁地标
- `CurrentTravel`: 当前旅行状态
